# gald3r v3.0.0 — Engine-Binary Distribution

**Status:** Released 2026-07-06.

---

## Headline

Your gald3r framework now ships as a compiled engine — the same file-first, IDE-native experience across 38+ platforms, with the proprietary engine protected as a signed binary instead of readable source.

---

## Why upgrade

- **Compiled engine distribution.** The gald3r engine ships as a signed binary; the coordination, worktree, workspace-control, triage, policy, medic, and verification logic is compiled, not shipped as readable source. Skills call the engine through a resolver — same behavior, protected IP.
- **38+ IDE platforms.** One framework, installed natively into Cursor, Claude Code, Gemini, Codex, Windsurf, and 30+ more — now including newer entrants like ZCode, Pi, and Zed.
- **Cross-platform, clean installs.** Stock-Linux/macOS installs work out of the box (python3-aware); character-encoding and legacy-script issues purged; every shipped file lint-verified.
- **Companion products, released alongside.** Agent v0.2.0 (signed cross-OS CLI) and Throne v0.2.0 (desktop control panel with in-app updater).

## Coming next (in development)

- **Valkyrie** — agent-to-agent coordination (presence, task-claiming, collision-free multi-agent runs). In development; not yet enabled.
- Hosted coordination + team tier — join the waitlist at gald3r.ai.
