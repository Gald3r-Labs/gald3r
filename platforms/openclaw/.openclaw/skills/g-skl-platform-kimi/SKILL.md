## 1. Platform Overview

**Kimi Code** — Moonshot AI's terminal-native coding agent, delivered as the open-source **Kimi
Code CLI** plus a VS Code extension and third-party editor integrations (JetBrains, Zed via ACP).
Model id `kimi-for-coding` / `kimi-k2` family. As of the 2026-07-03 rebrand it natively supports
**all six** gald3r-relevant extension primitives.

## 2. Config Layout

```
<project-root>/
├── AGENTS.md                            ← instruction file (generated by /init; injected via KIMI_AGENTS_MD)
├── .kimi-code/
│   ├── local.toml                       ← project-local workspace settings (gitignored)
│   └── skills/   <name>/SKILL.md        ← Agent Skills (native)
└── .agents/skills/ <name>/SKILL.md      ← ALSO discovered (cross-tool compatible)

$KIMI_CODE_HOME/            (default ~/.kimi-code/)
├── config.toml                          ← hooks ([[hooks]]) + settings (TOML)
├── AGENTS.md                            ← global instruction file
├── skills/   <name>/SKILL.md            ← user-level skills
├── agents/   <name>.yaml                ← built-in / custom agent specs (also --agent-file)
└── plugins/  <name>/plugin.json         ← Custom Plugins (Beta), via `kimi plugin install`
```

Skill discovery order: **Project > User > Extra > Built-in**.

## 3. gald3r Integration

Ship gald3r's `SKILL.md` tree into **`.kimi-code/skills/`** (native) or **`.agents/skills/`**
(cross-tool) + an **`AGENTS.md`** instruction file. Wire hooks in
**`$KIMI_CODE_HOME/config.toml`** (default `~/.kimi-code/config.toml`) via `[[hooks]]`; invoke
`g-hk-*.py` through `python <path>` (cross-platform, shell-agnostic). Map gald3r commands to Kimi
`/skill:<name>`.

```bash
gald3r platform install kimi --into <target-dir>
```

### Verify
```powershell
Test-Path AGENTS.md ; Test-Path .kimi-code/skills ; Test-Path .agents/skills
Select-String '\[\[hooks\]\]' "$env:USERPROFILE\.kimi-code\config.toml"
```

## 4. Common Pitfalls

- **Instruction file is `AGENTS.md`, not `CLAUDE.md`** — injected via the `KIMI_AGENTS_MD`
  template variable, unchanged by the rebrand.
- **Config directory renamed**: `.kimi/` → `.kimi-code/` (project), `~/.kimi/` → `~/.kimi-code/`
  (user, overridable via `KIMI_CODE_HOME`). Three formats across surfaces: hooks/settings are
  TOML, agent specs are YAML, skills are `SKILL.md`.
- **Post-rebrand cross-discovery narrowed** — `.claude/skills/` and `.codex/skills/` are **no
  longer** documented discovery paths; ship into `.kimi-code/skills/` or `.agents/skills/`
  instead of relying on legacy `.claude/` reuse.
- **User-defined commands = Skills/Plugins** — there is no dedicated standalone slash-command
  file; map gald3r commands to `/skill:<name>`.
- **Custom Plugins remain Beta** — do not assume long-term config stability for `plugin.json`.
