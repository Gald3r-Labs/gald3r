Score complexity and expand tasks or plan sprints. Activates **g-tasks** → EXPAND or SPRINT PLAN.

Activate the **g-tasks** skill:
- For complex tasks: EXPAND operation
- For sprint planning: SPRINT PLAN operation

Provide task ID for expansion, or no argument for full sprint plan.
