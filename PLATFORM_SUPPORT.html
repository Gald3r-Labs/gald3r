gald3r - Supported Platforms

The file-based AI-dev framework, one repo, packaged for 38 AI coding tools.

One binary, every platform. Since 4.0.0, every platform's overlay ships inside the signed gald3r binary — download it from gald3r_core releases, then run gald3r setup in your project and gald3r platform install <name> for your tool below. The old platforms/ and project_template/ file trees were retired from this repo on 2026-08-05 — the binary generates the exact, always-current overlay for all 38 platforms, so there is nothing left to copy by hand. (This page previously pointed at separate gald3r_platform_* repos, then at in-repo template trees; both are history now.)
